How this works

Reply to the reminder in plain words. The app sorts each sentence into Done, Tomorrow, or Blocked, saves it to the feed, and texts back a confirmation. A second text the same day gets added to that check-in as a reply. When the owner replies in the feed, the reply shows up here as a text.

This demo uses a simple keyword sorter. The live version would use AI, which handles messier wording.
